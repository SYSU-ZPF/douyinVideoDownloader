# 抖音视频批量下载器

基于 Tkinter、Playwright 和 Requests 的桌面工具。将多段抖音分享文本粘贴到窗口中，即可提取链接、选择保存目录并批量下载视频。

## 功能

- 从分享文本中提取多个 HTTP/HTTPS 地址，按出现顺序去重。
- 支持抖音短链接及视频页面链接，按顺序逐个解析、下载。
- 展示整体任务进度、当前视频下载百分比及已下载大小。
- 单个视频失败后继续处理后续链接，窗口日志显示每条任务的结果。
- 使用视频标题命名 MP4 文件，同名文件自动添加 `_2`、`_3` 等后缀。
- 下载时先写入 `.part` 临时文件，成功后改名；失败时清理临时文件。

## 环境准备

需要 Python 3、Tkinter，以及能够访问抖音网页和视频资源的网络环境。程序带有图形界面，需要在桌面环境中运行。

在终端进入项目目录，创建并启用虚拟环境：

```bash
cd /Users/xxx/videodownloader
python3 -m venv .venv
source .venv/bin/activate
```

安装 Python 依赖和 Playwright 使用的 Chromium 浏览器：

```bash
python -m pip install requests playwright
python -m playwright install chromium
```

检查 Tkinter 是否可用，以下命令应打开一个测试窗口，关闭后即可继续：

```bash
python -m tkinter
```

如果提示缺少 `tkinter` 或 `_tkinter`，需要为当前 Python 安装匹配的 Tk 支持；Tkinter 无法通过 `pip install tkinter` 安装。更换 Python 环境后，需在新环境中重新安装依赖。

## 启动与使用

启用虚拟环境后运行增强版程序：

```bash
python downloader_strong.py
```

1. 将一条或多条抖音分享文本粘贴到输入框，可以换行分隔，也可以混在同一段文本里。
2. 点击“开始批量下载”。
3. 选择本批视频的保存目录；取消目录选择则不会开始下载。
4. 查看进度条和窗口底部日志。批次结束后会弹出成功、失败数量。

例如，可以直接粘贴以下分享文本，无需手动删除描述：

```text
6.15 f@o.qE fBg:/ :8pm 10/19 从不害怕晒黑、素颜、变壮，我怕自己没有力量和自信。 初学自由泳一个月，新手阶段，努力提高自己的能力才是最重要的。新技能get～# 学游泳 # 游泳 # 日常生活 正常游泳穿搭无不良引导 https://v.douyin.com/eeOr-sxUB3Q/ 复制此链接，打开Dou音搜索，直接观看视频！
```

批量下载时，将其他视频的分享文本继续粘贴到后面即可。相同地址在同一批次中只处理一次；指向同一视频的不同地址仍会分别处理。建议让不同链接之间保留空格或换行。

## 进度说明

| 显示项 | 含义 |
| --- | --- |
| 整体进度 `3 / 10` | 已处理 3 条链接，共 10 条；已处理数量包含成功和失败 |
| 正在解析 | 浏览器正在加载视频页面并捕获播放地址，此时进度条滚动 |
| 当前视频百分比 | 服务器提供文件总大小时，显示百分比及已下载/总大小 |
| 总大小未知 | 服务器未提供可用总大小时，显示已下载大小，进度条滚动 |
| 下方日志 | 每条链接的保存路径或失败原因，仅在当前窗口中显示 |

## 常见问题

### 提示找不到浏览器

在运行程序的同一个 Python 环境中执行：

```bash
python -m playwright install chromium
```

### 未截获视频流、超时或下载失败

先检查链接能否在浏览器中正常打开，以及网络和保存目录是否可用。验证码、登录要求、视频下架或页面变化都可能导致解析失败。当前程序使用无头浏览器，未提供登录或手动完成验证码的界面。

失败链接可以从窗口日志中复制出来，再次粘贴下载；程序不会自动重试。

### 下载的视频是否一定无水印？

程序优先从视频详情中提取播放地址，并在必要时回退到其他视频资源地址。实际结果取决于页面返回的资源，无法保证每个视频都无水印。

## 当前范围

- 批量任务依次执行，暂不支持并发下载、暂停、取消或断点续传。
- 主要面向单个抖音视频分享链接；不提供主页全部作品、合集或图集批量下载。
- 地址提取支持 HTTP/HTTPS，但视频解析逻辑针对抖音，其他网站不保证可用。
- `downloader_strong.py` 为本文介绍的增强版入口；`downloader.py` 为目录中保留的另一份脚本。
